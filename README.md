## 牛奶蛋白过敏（CMPA）是什么

**牛奶蛋白过敏（CMPA，Cow's Milk Protein Allergy）** 是婴儿期最常见的食物过敏之一，指宝宝的免疫系统对牛奶中的蛋白质（如酪蛋白、乳清蛋白）产生异常免疫反应。敏宝在摄入含牛奶蛋白的食物后，可能出现湿疹反复、呕吐、腹泻、便血、哭闹不安、生长缓慢等表现。确诊后通常需要在医生指导下使用 **深度水解奶粉** 或 **氨基酸奶粉** 进行替代喂养，并严格回避日常饮食中的牛奶蛋白。

对敏宝家庭来说，最难的不是喝特殊配方粉，而是 **读配料表**——牛奶成分会以几十种"马甲词"藏在零食、调味品、辅食里。本仓库的核心价值，就是帮妈妈们系统掌握 **配料表检测** 与食物分类方法，让每一口都吃得安心。

## 使用说明

1. 新手妈妈建议先阅读 [`docs/feeding-guide.md`](docs/feeding-guide.md)，建立整体认知。
2. 购物前对照 [`docs/food-traffic-light.md`](docs/food-traffic-light.md) 判断食物红绿灯等级。
3. 购买包装食品时，用 [`docs/ingredient-aliases.md`](docs/ingredient-aliases.md) 逐项核对配料表；或直接使用上方在线工具粘贴检测。
4. 任何食物添加请遵循医生指导，逐一少量尝试，观察 3–5 天。

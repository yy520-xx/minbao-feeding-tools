# 配料表马甲词表（牛奶成分隐藏名称对照）

> 敏宝妈妈读包装食品配料表必备速查表
>
> 牛奶蛋白在加工食品中会以几十种"马甲"出现，光看"牛奶"两个字远远不够。本表把常见的牛奶马甲词按类别整理出来，购物时逐项排查。

---

## 一、直接含牛奶的（一眼识别）

| 马甲词 | 为什么警惕 |
| --- | --- |
| 牛奶、牛乳、鲜牛奶 | 直接就是牛奶蛋白 |
| 全脂乳粉、全脂奶粉 | 牛奶脱水喷雾干燥，蛋白浓缩，致敏性更强 |
| 脱脂乳粉、脱脂奶粉 | 虽去掉脂肪，但牛奶蛋白完整保留 |
| 乳清粉、乳清蛋白粉 | 从牛奶中提取的乳清蛋白，CMPA 主要过敏原之一 |
| 酪蛋白、干酪素 | 牛奶中另一大类主要蛋白，CMPA 过敏原 |
| 生牛乳、复原乳 | 本质都是牛奶 |
| 炼乳、淡炼乳 | 浓缩牛奶，含完整蛋白 |
| 奶液、乳液 | 即牛奶 |

## 二、加工乳制品（也要警惕）

| 马甲词 | 为什么警惕 |
| --- | --- |
| 奶油、稀奶油、淡奶油 | 从牛奶中分离的乳脂肪 + 乳蛋白 |
| 黄油、白脱、牛油（动物黄油） | 虽以脂肪为主，但常残留乳蛋白 |
| 奶酪、芝士、干酪 | 浓缩牛奶蛋白，致敏性高 |
| 炼乳、加糖炼乳 | 浓缩牛奶 |
| 奶精、植脂末 | 虽叫"植脂"，但多数含乳清蛋白 / 酪蛋白酸钠 |
| 酸奶、酸乳、发酵乳 | 含牛奶蛋白 |
| 奶粉、乳粉 | 任何"XX 粉"只要带"乳"字都要查 |

## 三、隐藏名称（最容易踩坑！）

这些词看似化学术语或工艺词，实则都来自牛奶：

| 马甲词 | 实际来源 | 警惕原因 |
| --- | --- | --- |
| 乳清蛋白、WPI、WPC | 牛奶乳清 | 主要过敏原 |
| 酪蛋白酸钠、酪蛋白酸钙 | 牛奶酪蛋白 | 酪蛋白衍生物，仍可能致敏 |
| 酪蛋白、casein | 牛奶酪蛋白 | 主要过敏原 |
| 乳球蛋白、β-乳球蛋白 | 牛奶乳清 | 主要过敏原 |
| 乳白蛋白 | 牛奶乳清 | 过敏原 |
| 乳铁蛋白 | 牛奶乳清 | 过敏原 |
| 乳糖、lactose | 牛奶提取糖 | 虽为糖，但工业乳糖常残留乳蛋白，严重敏宝需回避 |
| 乳粉、乳固体 | 牛奶干燥物 | 含完整蛋白 |
| 干酪素、酪素 | 牛奶酪蛋白 | 即 casein |
| 凝乳酶、凝乳 | 奶酪加工相关 | 可能含乳残留 |
| 乳脂、乳脂肪 | 牛奶脂肪 | 低脂款可能残留蛋白 |
| 乳蛋白 | 直接说明 | 含牛奶蛋白 |
| 牛乳香精、奶味香精 | 调味 | 部分含乳成分载体 |

## 四、"可能含牛奶"的高危加工品

这些产品**通常**含牛奶，但不同品牌配方不同，必须看具体配料表：

| 食品 | 为什么警惕 |
| --- | --- |
| 人造奶油、麦淇淋 | 很多品牌添加乳成分 |
| 植脂末、奶精 | 多数含酪蛋白酸钠、乳清粉 |
| 奶味饼干、奶香面包 | 必加奶粉 / 乳粉 |
| 巧克力、白巧克力 | 绝大多数含乳粉、乳清 |
| 沙拉酱、千岛酱 | 含奶油 / 乳成分 |
| 冰淇淋、雪糕 | 含牛奶、奶油 |
| 奶茶、奶咖 | 含牛奶 / 植脂末 |
| 婴幼儿米饼、泡芙、磨牙棒 | 看品牌，部分加奶粉调味 |
| 月饼、糕点 | 常加奶粉、黄油 |
| 方便面调料包 | 部分含乳粉增香 |
| 火腿、香肠 | 部分加乳蛋白做乳化 |

海淘或进口食品包装常见以下英文，见到就要警惕：

| 英文 | 中文 |

| Milk powder / Whole milk powder / Skim milk powder | 奶粉 / 全脂奶粉 / 脱脂奶粉 |
| Whey / Whey protein | 乳清 / 乳清蛋白 |
| Casein / Caseinate / Sodium caseinate | 酪蛋白 / 酪蛋白酸盐 / 酪蛋白酸钠 |
| Lactose | 乳糖 |
| Cream | 奶油 |
| Butter | 黄油 |
| Cheese | 奶酪 |
| Yogurt / Yoghurt | 酸奶 |
| Curd | 凝乳 |
| Ghee | 酥油（印度澄清黄油） |
| Milk solids | 乳固体 |
| Non-fat dry milk | 脱脂奶粉 |
| Butter milk / Buttermilk | 酪乳 / 脱脂乳 |

## 六、读配料表的三步法

1. **按含量从高到低读**：配料表第一位是含量最高的成分。
2. **逐行排查马甲词**：对照本表，只要出现任何一个马甲词，就视为含牛奶。
3. **警惕"等"字和复合配料**：如"复合调味料（含乳粉）"——括号里也要展开看。

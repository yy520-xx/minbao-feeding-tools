# 敏宝食物红绿灯表

> 适用对象：牛奶蛋白过敏（CMPA）宝宝家庭
>
> 等级说明：
> - 🟢 **绿灯（放心吃）**：不含牛奶蛋白，过敏风险低，可在医生指导下常规添加
> - 🟡 **黄灯（谨慎吃 / 少量尝试）**：本身不含牛奶，但属于常见高致敏食物，或加工过程易交叉污染，需逐一少量试
> - 🔴 **红灯（避免吃）**：含牛奶蛋白或高概率含牛奶成分，明确回避

> 注意：本表为通用科普参考，不替代医生建议。每个敏宝耐受度不同，新食物务必从极少量开始，连续观察 3–5 天。

---

## 一、谷物类

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 大米、米粉、大米粥 | 🟢 绿灯 | 最基础的低敏主食，敏宝首选 |
| 小米、小米粥 | 🟢 绿灯 | 低敏粗粮，易消化 |
| 燕麦（纯燕麦，无调味） | 🟢 绿灯 | 本身不含牛奶，但注意市售"奶香燕麦"可能含奶 |
| 玉米、玉米糊 | 🟢 绿灯 | 低敏主食 |
| 小麦（面粉、馒头、面条） | 🟡 黄灯 | 小麦本身不是牛奶，但部分宝宝合并小麦过敏；市售面条、馒头常加奶粉 / 乳粉 |
| 挂面、宝宝面条 | 🟡 黄灯 | 看配料表，选无奶粉、无乳清粉的纯小麦面条 |
| 面包、蛋糕、饼干 | 🔴 红灯 | 几乎必含牛奶 / 黄油 / 奶粉，自制无奶配方除外 |
| 麦片（调味即食款） | 🔴 红灯 | 通常含乳粉、奶精、奶油 |

## 二、蔬菜类

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 胡萝卜、南瓜、土豆、山药 | 🟢 绿灯 | 经典低敏蔬菜，辅食初期首选 |
| 西兰花、花菜、白菜、生菜 | 🟢 绿灯 | 低敏蔬菜 |
| 菠菜、油菜、油麦菜 | 🟢 绿灯 | 注意去草酸，焯水后食用 |
| 番茄、茄子、青椒 | 🟡 黄灯 | 少数宝宝对茄科敏感，逐一试 |
| 黄瓜、冬瓜、丝瓜 | 🟢 绿灯 | 低敏 |
| 菌菇类（香菇、平菇） | 🟡 黄灯 | 部分宝宝易过敏，少量尝试 |

> 蔬菜类整体安全性高，重点是烹饪时不要加黄油、奶油、奶粉。

## 三、水果类

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 苹果、梨、香蕉 | 🟢 绿灯 | 低敏水果，辅食初期首选 |
| 大米粥煮的苹果泥 | 🟢 绿灯 | 温和易消化 |
| 蓝莓、草莓、猕猴桃 | 🟡 黄灯 | 浆果类偏易致敏，少量试 |
| 橙子、橘子、柚子 | 🟡 黄灯 | 柑橘类易刺激肠胃，部分宝宝不耐受 |
| 芒果、菠萝 | 🔴 红灯 | 高致敏水果，敏宝期建议回避 |
| 猕猴桃 | 🟡 黄灯 | 易过敏，少量试 |

> 水果本身不含牛奶，红灯主要针对高致敏水果，而非牛奶蛋白。

## 四、肉蛋类

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 猪肉（瘦猪肉） | 🟢 绿灯 | 低敏肉类，辅食初期首选 |
| 鸡肉（鸡胸、鸡腿） | 🟢 绿灯 | 低敏肉类 |
| 牛肉 | 🟡 黄灯 | 部分敏宝合并牛肉过敏，需逐一试 |
| 鸡蛋（蛋黄） | 🟡 黄灯 | 鸡蛋是常见过敏原，建议 8 月龄后从蛋黄开始少量试 |
| 鸡蛋（全蛋 / 蛋白） | 🟡 黄灯 | 蛋白致敏性高于蛋黄，遵医嘱 |
| 鱼肉（鳕鱼、鲈鱼等低汞鱼） | 🟡 黄灯 | 鱼类是常见过敏原，逐一试，警惕交叉过敏 |
| 虾、蟹等海鲜 | 🔴 红灯 | 高致敏，敏宝期建议回避 |
| 加工肉（火腿肠、午餐肉） | 🔴 红灯 | 含乳制品、调味品复杂，不建议 |

## 五、豆类及制品

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 黄豆 | 🟡 黄灯 | 大豆是八大过敏原之一，约 10–20% CMPA 宝宝合并大豆过敏，少量试 |
| 豆腐 | 🟡 黄灯 | 加工后致敏性下降，但仍建议观察 |
| 豆浆（自制无糖） | 🟡 黄灯 | 同上，注意是否合并大豆过敏 |
| 豆奶粉、豆奶饮料 | 🔴 红灯 | 市售产品常含乳粉、奶精 |
| 鹰嘴豆、扁豆 | 🟡 黄灯 | 少量试，观察反应 |

## 六、坚果类

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 花生 | 🔴 红灯 | 高致敏，敏宝期回避 |
| 核桃、杏仁、腰果 | 🔴 红灯 | 高致敏坚果，回避 |
| 花生酱、坚果粉 | 🔴 红灯 | 高致敏 + 交叉污染风险 |
| 坚果奶（燕麦奶、杏仁奶） | 🟡 黄灯 | 注意配料表，部分产品含乳粉或牛奶蛋白残留 |

## 七、奶制品（重点回避）

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 牛奶、鲜牛奶、纯牛奶 | 🔴 红灯 | 直接过敏原 |
| 配方奶粉（普通 1/2/3 段） | 🔴 红灯 | 含完整牛奶蛋白 |
| 酸奶、乳酸菌饮料 | 🔴 红灯 | 含牛奶蛋白 |
| 奶酪、芝士、奶油 | 🔴 红灯 | 浓缩牛奶蛋白 |
| 黄油、炼乳 | 🔴 红灯 | 含乳固体 |
| 奶粉（全脂 / 脱脂） | 🔴 红灯 | 配料表常见隐藏项 |
| 深度水解奶粉 | 🟢 绿灯（遵医嘱） | 医生指导下使用的替代配方 |
| 氨基酸奶粉 | 🟢 绿灯（遵医嘱） | 医生指导下使用的替代配方 |
| 豆奶配方（无敏配方） | 🟡 黄灯 | 需确认无大豆过敏 |

## 八、调味品与加工食品

| 食物 | 红绿灯 | 理由 |
| --- | --- | --- |
| 盐、糖 | 🟢 绿灯 | 不含牛奶（少量使用） |
| 酱油 | 🟡 黄灯 | 选无奶酿造酱油，看配料表 |
| 醋 | 🟢 绿灯 | 纯酿造醋不含牛奶 |
| 沙拉酱、千岛酱 | 🔴 红灯 | 含奶油 / 蛋黄 / 乳成分 |
| 巧克力、可可粉 | 🔴 红灯 | 绝大多数含乳粉、乳清 |
| 植脂末、奶精 | 🔴 红灯 | 含乳清蛋白、酪蛋白酸钠 |
| 人造奶油、麦淇淋 | 🔴 红灯 | 常含乳成分 |
| 婴幼儿零食（米饼、泡芙） | 🟡 黄灯 | 必须看配料表，选无奶款 |
| 面包、蛋糕 | 🔴 红灯 | 含牛奶、黄油 |

## 快速使用建议

1. **绿灯食物**：作为日常主食和辅食主力。
2. **黄灯食物**：每次只加一种，从一小勺开始，观察 3–5 天无反应再加量。
3. **红灯食物**：彻底回避，直到医生评估后再考虑是否尝试。
4. 任何包装食品，**必须看配料表**，对照 [配料表马甲词表](ingredient-aliases.md) 逐项排查。
